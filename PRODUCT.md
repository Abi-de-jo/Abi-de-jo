# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers, collaborators, recruiters, and potential clients visiting Abi's GitHub profile to quickly understand who he is, what he builds, and how to contact him.

## Product Purpose

Turn the GitHub profile README into a memorable, useful developer portfolio that communicates Abi's full-stack capabilities and invites relevant visitors to explore his work or start a conversation.

## Positioning

The profile behaves like a compact developer game world rather than a conventional badge wall or static portfolio banner.

## Operating Context

The experience is rendered inside GitHub's README surface. It may use Markdown, GitHub-safe HTML, linked images, and animated SVG, but cannot rely on JavaScript or custom page-level CSS.

## Capabilities and Constraints

- Keep the profile readable on desktop and mobile GitHub layouts.
- Use animated SVG and clickable links for game-like movement and navigation.
- Preserve truthful developer skills and contact destinations already present in the repository.
- Do not fabricate employers, clients, project metrics, awards, or testimonials.

## Brand Commitments

- Identity: Abi / CodeByAbi / GitHub handle `Abi-de-jo`.
- Personality: nerdy, playful, highly technical, builder-minded, and game-inspired.
- The experience should feel interactive and alive, not like one generated static image.
- A developer desk, laptop, quests, skills, and game mechanics are binding motifs.

## Evidence on Hand

- Existing profile content and links in `README.md`.
- Existing public GitHub activity and language data available through live profile widgets.
- No verified commercial claims or testimonials are present; future work must not invent them.

## Product Principles

- The whole profile is one coherent game world.
- Motion must communicate activity rather than decorate empty space.
- Visitors understand Abi's role, capabilities, and contact path within the first screen.
- Visual personality never makes the profile difficult to scan.
